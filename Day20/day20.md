# Day 20 - Face Puzzle Game

## Overview

On Day 20 of the Claude 60 Days Challenge, I created an interactive Face Puzzle Game using Claude AI. The application allows users to capture their photo through a webcam and convert it into a playable puzzle.

## Features

* Webcam photo capture
* Dynamic puzzle generation
* Difficulty levels:

  * 3×3
  * 4×4
  * 5×5
* Drag-and-drop support
* Mobile touch interactions
* Timer tracking
* Move counter
* Local leaderboard
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* MediaDevices API
* Drag and Drop API

## Learning Outcomes

* Learned how browser camera permissions work
* Implemented image-based puzzle generation
* Improved understanding of drag-and-drop events
* Added touch support for mobile devices
* Built game state management logic
* Enhanced frontend UI/UX design skills

## Challenges Faced

* Managing puzzle piece positioning
* Handling different screen sizes
* Supporting both desktop and mobile interactions
* Maintaining accurate timer and move tracking
