# 🧠 Cognitive Pattern Explorer

An interactive psychology-inspired self-reflection web application built using **HTML, CSS, and Vanilla JavaScript**.

The experience is designed to help users explore different thinking tendencies through engaging scenarios, drag-and-drop activities, and personalized reflections. It is educational only and does **not** provide psychological diagnoses or clinical assessments.

## ✨ Features

* Calm Mode & Stress Mode experience
* Interactive multi-chapter journey
* Thinking style exploration
* Drag-and-drop priority ranking
* Interactive thinking timeline mapping
* Personalized reflection journal
* Percentage-based insight generation
* Progress tracking
* Smooth animations
* Responsive design
* Keyboard accessibility
* Reduced motion support
* Fully offline
* Single HTML file
* No frameworks or external dependencies

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript

## 🎯 Learning Goals

This project demonstrates:

* Interactive UI development
* State management in Vanilla JavaScript
* Reusable drag-and-drop components
* Dynamic scoring and insight generation
* Responsive interface design
* Accessibility best practices
* Offline-first application architecture

> **Educational Disclaimer:** This application is designed solely for learning and self-reflection. It does not diagnose, assess, or provide mental health advice.
