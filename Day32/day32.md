# 🚀 Think Like a Marketing Strategist: Grow This Brand

## Day 32 – Claude AI Challenge

An interactive single-file React application that teaches users how to think like a marketing strategist through real-world decision making instead of simply generating marketing content.

## 🎯 Overview

This educational simulator helps beginners understand the complete marketing strategy process by guiding them through audience research, platform selection, content planning, growth strategy, and unexpected marketing challenges.

Users can replay the experience with different business scenarios or build a strategy for their own personal brand.

## ✨ Features

* 🏢 Use your own business
* 🙋 Build a personal brand
* 🎲 Random business/client generator
* 👥 Audience research and customer understanding
* 📱 Social platform selection with strategic explanations
* 📚 Content pillar planning
* 📅 30-day growth roadmap
* ⚡ Random marketing events with multiple outcomes
* 📊 Comprehensive Growth Report
* 🤖 Claude prompt engineering cards throughout the experience
* 🌙 Modern responsive dark UI
* 🔄 Fully replayable experience

## 🛠 Tech Stack

* React (CDN)
* Babel JSX
* HTML5
* CSS3
* Vanilla JavaScript

## 🎓 Learning Outcomes

* Marketing strategy fundamentals
* Audience-first thinking
* Platform selection strategies
* Content planning
* Personal branding principles
* Growth planning
* Strategic decision making
* Prompt engineering for marketing workflows

## 🚀 How to Run

1. Download the HTML file.
2. Open it in any modern web browser.
3. No installation or backend required.
4. Runs completely offline.
