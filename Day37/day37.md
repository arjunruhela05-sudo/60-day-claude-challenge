# Day 37 – Task Compass

## Overview

Task Compass is an interactive educational web application that teaches users how organizations assign ownership, route work, and collaborate effectively through scenario-based challenges.

The application is built as a **single offline HTML file** using **HTML, CSS, and Vanilla JavaScript**, requiring no backend, frameworks, or external APIs.

---

## Objectives

* Learn task ownership principles
* Understand task routing across departments
* Improve organizational thinking
* Practice collaboration and decision-making
* Explore different workplace environments

---

## Features

* Workplace Type Selection
* Stage 1: Who Owns This?
* Stage 2: Task Routing
* Stage 3: Collaboration Challenge
* Organizational Thinking Dashboard
* Interactive learning experience
* Responsive design
* Offline support
* Beginner-friendly interface

---

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

---

## Project Workflow

1. Choose a workplace type
2. Complete the Task Ownership stage
3. Route tasks to the correct teams
4. Solve collaboration challenges
5. Review your Organizational Thinking Dashboard
6. Replay with another workplace type
