# Day 4 - Chain-of-Thought Prompting

## Objective

Today I learned about Chain-of-Thought Prompting and how breaking a problem into smaller steps helps AI generate more accurate and personalized responses.

---

## Prompting Process

Claude first asked me four questions:

1. What is your current situation?

   * Student

2. What skills do you currently have?

   * Web Development

3. What is your primary goal?

   * Get a Job

4. What is your target timeline?

   * 1 Year

Using these answers, Claude generated a personalized AI career roadmap.

---

## My Personalized Career Roadmap

### Phase 1 (Months 1-3)

* Strengthen JavaScript fundamentals.
* Build responsive websites using HTML, CSS, and JavaScript.
* Learn Git and GitHub.

### Phase 2 (Months 4-6)

* Learn React.js.
* Build 3-4 portfolio projects.
* Start using AI tools to improve productivity.

### Phase 3 (Months 7-9)

* Learn backend basics (Node.js and Express).
* Build full-stack applications.
* Improve problem-solving skills.

### Phase 4 (Months 10-12)

* Polish portfolio.
* Optimize GitHub profile.
* Apply for internships and entry-level jobs.
* Prepare for technical interviews.

---

## Biggest Insight

I realized that achieving a big goal becomes much easier when it is broken down into small, manageable steps. Having a structured roadmap provides clarity and direction.

---

## Key Learnings

* Chain-of-Thought Prompting helps AI think step by step.
* Better context produces better personalized outputs.
* Structured planning makes long-term goals easier to achieve.
* AI can be used as a career planning assistant.
