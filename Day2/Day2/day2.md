# Day 2 - Prompt Engineering

## Objective

Today I explored the difference between a simple prompt and an engineered prompt using Claude AI.

---

## Lazy Prompt

```
Create an image explaining Prompt Engineering.
```

---

## Engineered Prompt

```
You are an AI educator teaching complete beginners.
Explain Prompt Engineering in simple language.

Include:
- What Prompt Engineering is
- Why it matters when using AI tools like Claude
- One example of a weak prompt
- One example of an improved prompt
- Three practical benefits of writing better prompts

Also create a LinkedIn-ready image concept.

Image Requirements:
- Square LinkedIn post (1080×1080)
- Claude-inspired brown, beige and cream colors
- Professional and minimal design
- Modern infographic style
- Clear sections and icons
```

---

## Comparison

### Lazy Prompt Output

* Simple and generic.
* Limited explanation.
* Basic visual structure.

### Engineered Prompt Output

* Well organized.
* Better explanation quality.
* Professional infographic design.
* Included examples and practical benefits.
* More suitable for sharing on LinkedIn.

---

## Key Learnings

* Better prompts produce better AI outputs.
* Context and structure improve response quality.
* Specifying format and audience helps AI understand the task.
* Prompt Engineering is an essential skill for working effectively with AI.

---

## Reflection

Today I learned that AI is only as effective as the instructions we provide. A small improvement in prompt quality can create a huge improvement in the final result.

Learning how to communicate clearly with AI is becoming as important as learning to code.
