# 🕵️ Marketing Detective

A premium detective-style educational web application that transforms marketing analysis into an engaging investigation game.

Instead of reading marketing case studies, users become detectives who analyze campaign evidence, identify hidden mistakes, and solve fictional marketing mysteries.

## ✨ Features

* 🎯 Premium detective-themed interface
* 📁 Randomized fictional marketing cases
* 🧩 Interactive investigation workflow
* 📌 Draggable evidence board
* 📊 Campaign performance analysis
* 💬 Customer feedback investigation
* 📱 Social media performance insights
* 🕵️ Hidden marketing mistake discovery
* 🎉 Animated "Case Closed" experience
* 📚 Detailed learning report after every case
* 🌙 Responsive dark theme
* 💻 Single-file offline HTML application

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript
* React (CDN) / Vanilla JavaScript fallback
* Responsive Design
* Modern UI/UX Principles

## 🎮 How It Works

1. Receive a fictional marketing case.
2. Review campaign details and objectives.
3. Investigate customer feedback, metrics, and social performance.
4. Drag and organize evidence on the investigation board.
5. Identify the primary marketing mistake.
6. Close the case and receive a detailed explanation with improvement suggestions.
