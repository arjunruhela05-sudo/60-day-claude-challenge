# 📰 Media Integrity Analyzer

**Media Integrity Analyzer** is a single-file interactive HTML application that teaches media literacy through guided discovery rather than traditional quizzes.

Instead of testing existing knowledge, the application helps users learn how headlines, emotional language, and audience targeting influence the way information is consumed.

## 🚀 Features

* Interactive **Headline Detective** challenge
* **Emotion Detector** for identifying persuasive language
* Real-time Media Integrity metrics
* Headline Accuracy analysis
* Emotional Manipulation insights
* Audience Targeting evaluation
* Source Reliability indicators
* Overall Media Integrity Dashboard
* Personalized learning summary
* Replay with completely new fictional scenarios
* Responsive premium dark editorial interface
* Smooth animations and modern UI
* Built with **HTML, CSS, and Vanilla JavaScript**
* Works completely offline in a **single HTML file**

## 🎯 Learning Objectives

* Recognize clickbait headlines
* Identify emotional manipulation techniques
* Evaluate the reliability of information
* Develop critical thinking skills for consuming digital media
* Practice responsible media literacy through interactive exercises

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## 📌 Project Highlights

This project focuses on **interactive learning**, combining modern frontend design with instructional techniques to create an engaging educational experience. Users learn by observing, analyzing, making decisions, and reviewing guided explanations instead of simply receiving answers.
