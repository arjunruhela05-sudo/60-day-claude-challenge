# 📄 PDF Splitter & Merger

A premium single-page PDF utility built with **HTML, CSS, and Vanilla JavaScript** that enables users to split and merge PDF files entirely within the browser.

## ✨ Features

### PDF Splitter

* Upload PDF files
* Automatic page detection
* Visual page thumbnails
* Split by page numbers
* Split by custom page ranges
* Split after specific pages
* Split every N pages
* Extract selected pages
* Multiple split ranges in one operation
* Page range validation
* Preview output structure before processing

### PDF Merger

* Drag-and-drop file upload
* Merge multiple PDF files
* Sort files before merging
* File previews
* Total file and page statistics
* Output estimation
* One-click PDF download

## 🎨 UI & UX Highlights

* Premium commercial-style dashboard
* Responsive design
* Dark Mode
* Smooth animations
* Loading indicators
* Accessibility-focused interface
* Keyboard shortcuts
* Interactive micro-interactions
* Modern typography and layout

## 🔒 Privacy First

All PDF processing is performed locally inside the browser. No files are uploaded to external servers, ensuring complete privacy and offline functionality after the initial load.
