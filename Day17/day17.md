Day 17 - Fuel Analytics Dashboard 🚗📊
Project Overview

Built a Fuel Analytics Dashboard that compares different fuel types based on running cost, maintenance cost, emissions, and vehicle age. The dashboard presents data through custom SVG charts and KPI cards, helping users evaluate fuel efficiency and sustainability.

Features
KPI Cards for key fuel metrics
Cost per Kilometer Analysis
CO₂ Emission Comparison
Vehicle Age vs Running Cost Visualization
E85 Fuel Feasibility Analysis
Animated SVG Gauge Score
Glassmorphism UI Design
Responsive Layout
Pure HTML, CSS, SVG, and JavaScript (No External Libraries)
Metrics Included
Average Cost per Kilometer
Average CO₂ Emission per Kilometer
Average Maintenance Cost per Kilometer
Average Refuel/Recharging Time
Vehicle Age Bucket Analysis
E85 Cost Savings & Running Penalty
Break-even Fuel Price Calculation
Fuel Suitability Recommendations
Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
SVG Graphics
Key Learnings
Creating custom SVG visualizations
Building interactive dashboards without libraries
Data-driven UI design
Glassmorphism styling techniques
Dashboard layout and information hierarchy
Fuel efficiency and sustainability analysis
