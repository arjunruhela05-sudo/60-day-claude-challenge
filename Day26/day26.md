# 🏥 Prior Authorization Workflow Simulator

An interactive healthcare workflow simulator built with **HTML, CSS, and JavaScript** that demonstrates the complete Prior Authorization (PA) process between patients, providers, and insurance payers.

## 📌 Overview

This simulator helps users understand the complex Prior Authorization workflow through a visual drag-and-drop experience. It combines education with interactivity by allowing users to complete medical necessity reviews, collect required documentation, submit requests, and experience different payer outcomes.

---

## ✨ Features

* Multiple patient case scenarios
* Interactive drag-and-drop workflow
* Medical necessity evaluation
* Documentation collection checklist
* Provider, Patient, and Payer workflow lanes
* Progress tracking system
* Dynamic efficiency score
* Randomized approval, pending, and denial outcomes
* Appeal and Peer-to-Peer review simulation
* Educational guidance throughout the workflow
* Workflow summary dashboard
* Confetti celebration for approved cases
* Responsive design
* Pure HTML, CSS, and JavaScript
