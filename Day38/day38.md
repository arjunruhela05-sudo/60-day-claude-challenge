# Day 38 – Typing Speed Studio

## Project Overview

Today I created **Typing Speed Studio**, an offline typing practice application generated with Claude AI. The application provides multiple typing modes, real-time feedback, and an analytics dashboard to help users improve their typing speed and accuracy.

## Features

* Multiple typing practice modes
* Real-time typing feedback
* Words Per Minute (WPM) tracking
* Accuracy calculation
* Performance analytics dashboard
* Responsive user interface
* Fully offline functionality
* Single HTML file (HTML + CSS + JavaScript)

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Claude AI

## Workflow

1. Opened Claude AI.
2. Set effort level to **Low**.
3. Used the **Typing Speed Studio** prompt.
4. Answered the interview questions.
5. Generated the complete HTML application.
6. Saved and tested the application locally.
7. Tried different typing modes.
8. Completed multiple typing sessions.
9. Reviewed the analytics dashboard.
10. Captured screenshots and documented the project.

## Key Learnings

* Learned how AI can generate complete educational web applications.
* Understood the importance of interactive user experiences.
* Explored performance tracking using typing analytics.
* Improved prompt engineering skills through AI-assisted development.
* Practiced testing and documenting AI-generated projects.
