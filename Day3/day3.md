# Day 3 - Role-Based Prompting

## Objective

Today I learned how Role-Based Prompting changes AI outputs by assigning different expert perspectives to the same task.

## Prompt Used

### Normal Prompt

Create an image showing how a student can build a successful AI-powered product.

### Founder Persona Prompt

Act as an experienced startup founder.

Create an image showing how a student can build a successful AI-powered product.

### Developer Persona Prompt

Act as a senior software developer.

Create an image showing how a student can build a successful AI-powered product.

## Comparison

### Normal Output

The output provided a general perspective.

### Founder Output

The output focused on business strategy, customers, market validation, growth, and revenue.

### Developer Output

The output focused on technical implementation, software architecture, tools, coding, and development processes.

## Key Learnings

* AI responses change significantly when given a specific role.
* Different personas provide different viewpoints.
* Founder personas focus on business outcomes.
* Developer personas focus on technical execution.
* Role-Based Prompting improves the relevance of AI-generated content.

## Reflection

Today I learned that assigning a role to AI can dramatically improve the quality and focus of the output. The same task can produce very different results depending on the perspective provided to the AI.
