# 📊 Compare & Decide Builder

## Overview

Compare & Decide Builder is a premium single-page web application that helps users make informed decisions by comparing multiple options using real-world research, customizable criteria, and transparent scoring.

Rather than relying on assumptions, the application combines verified data, adjustable weightings, and live rankings to guide users toward confident decisions.

## Features

* 🎯 Interactive MCQ onboarding
* 📊 Live weighted scoring system
* ⚖️ Customizable comparison criteria
* 📈 Dynamic ranking updates
* 📚 Sources panel with citations
* 🔍 Research methodology section
* 🚩 Estimate & placeholder indicators
* 📱 Fully responsive premium UI
* ⚡ Loading, empty-state, and edge-case handling
* 🌙 Modern dashboard experience

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
