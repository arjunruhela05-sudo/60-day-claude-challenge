🕵️ Digital Footprint Intelligence Dashboard

An interactive dashboard that visualizes a user's digital footprint through privacy analytics, exposure metrics, and behavioral insights.

This project was created during Day 21 of my Claude AI 60 Days Challenge.

🚀 Features
📊 Digital Footprint Score
🔒 Privacy Score Analysis
🌐 Exposure Heatmap
🏢 Company Exposure Ranking
📑 Data Collection Matrix
📡 Risk Radar
🤖 AI-Based Digital Twin Profile
💎 Most Valuable Data Assets
🎯 Privacy Improvement Simulator
📈 Final Privacy Verdict
🌙 Modern Dark Theme
📱 Responsive Design
🛠 Built With
HTML5
CSS3
Vanilla JavaScript
Claude AI
📌 Project Goal

The purpose of this project is to demonstrate how data from different online services can be represented through an intuitive dashboard. It focuses on presenting privacy-related insights in a visually engaging way while distinguishing factual information from estimated analysis.
