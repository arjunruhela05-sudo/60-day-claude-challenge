# Day 31 – AI Supply Chain Control Tower

## Overview

This project is an interactive **AI Supply Chain Control Tower Simulator** built as part of my **Claude AI 60 Days Challenge**.

The simulator recreates a real-world supply chain operations environment where users monitor operational alerts, prioritize incidents, select corrective actions, and evaluate how each decision affects operational KPIs.

## Features

* Interactive operational alerts
* Incident prioritization system
* Decision-based corrective actions
* Dynamic KPI updates
* Performance dashboard
* Replay functionality for improving results
* Beginner-friendly interface
* Single-file HTML application
