# Day 35 – Prompt Puzzle

## Overview

For Day 35 of the **Claude AI 60 Days Challenge**, I created an interactive **Prompt Puzzle** HTML application using Claude AI. The project is designed to teach prompt engineering through practical challenges, allowing users to experiment with different prompts and evaluate their effectiveness.

## Features

* Interactive Prompt Puzzle experience
* Three prompt engineering challenges
* Prompt Performance Report
* Replay mode with different domains
* Adjustable difficulty levels
* Beginner-friendly interface
* Fully offline single HTML application

## What I Learned

* How prompt structure influences AI responses.
* The importance of providing clear context and constraints.
* Why iterative prompt refinement produces better results.
* How interactive applications can make AI concepts easier to understand.
