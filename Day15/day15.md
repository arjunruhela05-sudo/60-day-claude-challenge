# Personal Life Analysis Consultant - Vedic Astrology Dashboard

## Day 15 - Claude 60 Days Challenge

A visually rich and structured Vedic Astrology Dashboard designed using advanced prompt engineering and AI-generated design principles. This project transforms traditional astrological reports into an intuitive dashboard format, making complex insights easier to understand and analyze.

## Features

* Personal Profile Overview
* Lagna (Ascendant), Moon Sign, Sun Sign & Nakshatra
* Birth Chart (North Indian Style)
* Planetary Positions Table
* Life Score Visualization
* Strengths & Weaknesses Analysis
* Career Suitability Assessment
* Suitable Career Recommendations
* Wealth Potential Analysis
* Career & Wealth Timeline
* Marriage & Relationship Insights
* Current Dasha Analysis
* 5-Year Forecast
* Personalized Remedies & Guidance

## Objectives

The goal of this project was to explore how AI can be used to generate professional dashboard layouts through detailed prompt engineering while organizing large amounts of information into a user-friendly interface.

## Technologies & Concepts

* Prompt Engineering
* AI-Assisted Design
* Information Architecture
* Dashboard UI/UX Design
* Data Visualization
* Vedic Astrology Report Structuring

## Key Learnings

* Structuring prompts for complex dashboard generation
* Designing clear information hierarchies
* Creating visually appealing report layouts
* Converting textual insights into graphical representations
* Improving AI design outputs through iterative prompting
