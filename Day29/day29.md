# 🚚 Operation Lifeline: Supply Chain Crisis Lab

An interactive supply chain crisis management simulator built as a **single-file React application** using HTML, CSS, JavaScript, React CDN, and Babel JSX.

## 📌 Overview

Operation Lifeline places players in the role of a Supply Chain Crisis Manager responsible for guiding a fictional company through unexpected disruptions. Every decision affects business performance, making the experience both educational and engaging.

## ✨ Features

* Random company generation
* Dynamic crisis scenarios
* War Room strategic decision system
* Four-round supplier negotiation simulator
* CEO Boardroom leadership assessment
* AI investment planning module
* Executive performance dashboard
* Personalized feedback and recommendations
* Animated progress bars and score tracking
* Responsive premium dark-themed interface
* Fully offline single HTML file

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* React (CDN)
* Babel JSX

## 🎯 Learning Outcomes

* React state management with Hooks
* Component-based UI architecture
* Interactive simulation design
* Enterprise dashboard development
* Supply chain and operations concepts
* Decision-driven user experience design

## 🚀 How to Run

1. Download the HTML file.
2. Open it in any modern web browser.
3. No installation, backend, or internet connection required.
