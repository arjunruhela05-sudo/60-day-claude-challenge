# 🦈 AI Shark Tank Simulator

An interactive AI-powered Shark Tank experience where users pitch their startup ideas to virtual investors and receive intelligent feedback, startup scores, valuation estimates, and investment decisions.

## ✨ Features

* Startup idea submission
* Four unique AI investor personas
* Interactive pitch session
* Investor Q&A simulation
* Dynamic startup scoring
* Investment recommendation engine
* Suggested valuation
* Funding estimation
* Modern Shark Tank inspired UI
* Responsive layout
* Confetti celebration
* PDF report generation
* Leaderboard
* Share results functionality

## 🛠 Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)
* Responsive Design
* Local Storage

## 🎯 Learning Objectives

This project was created as **Day 25** of my **60 Days Claude AI Challenge**, focusing on:

* AI product design
* Prompt engineering
* Interactive UI/UX
* Front-end application architecture
* Startup evaluation workflows

A high-fidelity UI mockup demonstrates the complete user journey—from submitting a startup idea to receiving investment feedback and celebrating successful funding.
