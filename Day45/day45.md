# 🧠 AI Decision Report Dashboard

An interactive AI-powered decision-making dashboard created during **Day 45 of the Claude AI 60-Day Challenge**.

## 📌 Overview

This project converts a guided decision-making interview into a visually rich dashboard that helps users compare options, identify biases, evaluate risks, and confidently choose the best path.

## ✨ Features

* Interactive 4-step interview
* Real Decision Summary
* Option Comparison Cards
* Assumption Buster
* Decision Matrix with Animated Progress Bars
* Premortem Failure Analysis
* 7-Day Decision Validation Plan
* AI Verdict Section
* Shareable Summary Cards
* Responsive Modern Dark UI

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* Claude AI Prompt Engineering

* Data Visualization Concepts
* Responsive Web Design
