# 🏥 Prior Authorization Story Simulator

## 📌 Overview

The **Prior Authorization Story Simulator** is an educational web application designed to explain the healthcare prior authorization (PA) process through an interactive story.

Users follow Rahul (Patient) and Priya (Healthcare Operations Specialist) across eight guided scenes, learning how insurance authorization works from diagnosis to final approval.

---

## ✨ Features

* Interactive story-based learning
* 8 educational healthcare scenes
* Chat-style conversation interface
* Progress bar for learning journey
* Choice-based navigation
* Beginner-friendly explanations
* Healthcare dashboard UI
* Responsive design
* Append-only chat rendering using `createElement()` and `appendChild()`

---

## 📖 Story Flow

1. Doctor Visit
2. Insurance Roadblock
3. What is Prior Authorization?
4. Insurance Review
5. Denial
6. Appeal
7. Approval
8. Final Takeaways
